# ТЗ: Информация о точке трека по клику

**Проект:** GPXSee (форк `GlucoPlan/GPXSee`)
**Дата:** 2026-10-18
**Статус:** реализовано (2026-10-18)

## 1. Цель

По клику на линию трека на карте показывать данные о ближайшей к месту клика
точке трека.

## 2. Требования

1. **Действие — клик** левой кнопкой по линии трека (наведение не используется).
2. **Выбор точки:** берётся ближайшая к месту клика точка трека, если она не
   дальше ~10 px (экранных) от курсора. Клик дальше от трека — обычное
   поведение карты, окно не открывается.
3. **Окно** — существующее всплывающее окно трека, дополненное блоком
   «Точка» сверху; ниже — прежняя информация о треке (название, длина, время,
   дата, ссылки, файл). Существующая информация не теряется.
4. **Поля блока «Точка»** (строка выводится, только если значение есть):
   - дата и время (в часовом поясе из настроек GPXSee);
   - координаты (в формате координат из настроек);
   - высота;
   - скорость;
   - расстояние от начала трека;
   - время от начала трека;
   - пульс, каденс, мощность, температура.
   Единицы — из настроек GPXSee (метрические/имперские/морские).
5. **Отметка точки:** маркер трека на карте ставится в выбранную точку,
   ползунок на графиках сдвигается в соответствующую позицию (как если бы
   пользователь передвинул ползунок графика сам).
6. **Совместимость с фильтром по времени:** доступны только видимые точки
   (после фильтра).
7. Маршруты (routes) и точки (waypoints) — без изменений.

## 2а. Как реализовано

- `Track::pointInfo()` (`src/data/track.cpp`) — данные точек, выровненные 1:1
  с линией трека `Track::path()` (те же пропуски статистических выбросов и
  точек остановки): сама точка, расстояние и время от старта, скорость
  (из файла, если включено «использовать скорость из файла», иначе расчётная).
- `PathItem::mousePressEvent` (`src/GUI/pathitem.cpp`) — поиск ближайшей
  точки в радиусе 10 экранных px (с учётом цифрового зума), блок «Точка»
  в начале окна, затем прежняя информация о треке.
- `TrackItem::pointInfo` (`src/GUI/trackitem.cpp`) — заполнение полей. Единицы
  и подписи единиц — существующие переводы GPXSee (км/ч, уд/мин, об/мин, Вт,
  °C/°F); формат координат — из настроек.
- Сигнал `PathItem::markerPositionRequested` → `MapView` → `GUI` двигает
  ползунок текущей вкладки графиков и маркеры на карте (тот же механизм, что
  при ручном движении ползунка). Если графика у трека нет — двигается только
  маркер этого трека.
- При включённом фильтре по времени «расстояние/время от старта» считаются от
  начала **видимого** отрезка (как и вся статистика трека).
- Порядковый номер точки не выводится: из-за пропуска выбросов и фильтра он не
  совпадал бы с номером точки в файле.
- Перевод — `lang/gpxsee_ru.ts`, контекст `TrackItem`.

## 3. Критерии приёмки

1. Клик по треку → окно с блоком «Точка» и данными ближайшей точки + данные
   трека.
2. Значения соответствуют точке (время/координаты/высота совпадают с GPX).
3. Маркер на карте стоит в выбранной точке, ползунок графика — там же.
4. Клик в стороне от трека (> ~10 px) окно не открывает.
5. Поля без данных в файле не показываются.
